I'm a network and computer security graduate interested in the overlap between infrastructure and software: running systems, understanding why things break, and building tools that make them easier to manage.

Most of my projects involve self-hosted services, automation, performance diagnostics, or experimenting with how software and games work internally.

## Selected work

**Homelab & infrastructure**  
A Proxmox-based environment with Linux and Windows virtual machines, Docker services, self-hosted applications, and a SvelteKit management portal. I use it to work on networking, monitoring, deployment, and system administration.

**Developer tools & automation**  
Python, C++, and scripting projects for diagnostics, repeatable workflows, and performance-sensitive tasks. I enjoy tracing problems to their source rather than guessing at optimizations.

**Game tooling & mods**  
Borderlands 2 PythonSDK development focused on controller input, movement systems, quality-of-life features, and profiling. Some of this work is private while release preparation continues.

**Prototypes & experiments**  
Unity game prototypes and small applications where I can try new ideas, learn unfamiliar tools, and put them to practical use.
